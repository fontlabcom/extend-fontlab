# Frontend notices


The [browser-component record](assets/current-frontend-notices.json) binds the retained MaterialX 10.1.5 browser assets to exact upstream notices, package archives and source maps. The existing catalogue and third-party product terms remain unchanged.

The [English-only omission manifest](assets/english-search-omissions.json) binds all 34 unused lunr-languages 1.14.0 helpers, including Wordcut and TinySegmenter. The build rejects theme/search-language, corpus, vendor-set/hash and local HTML-reference drift before removing them. Nine core vendor assets remain byte-identical. Historical complete outputs remain recovery evidence; omitted helpers are not represented as currently distributed or relicensed.

The main source map retains 211 preferred sources, including 128 exact NPM source matches; the worker map retains 13 sources, including Lunr 2.3.9. The exact clipboard distribution embeds its dependencies; select, good-listener and delegate retain their upstream README MIT link and Zeno Rocha attribution, without invented standalone licence text or dates. CSS maps retain source names without embedded source bodies.

Material Design icons retain the Pictogrammers notice and Apache 2.0 icon terms or specifically stated underlying terms; code is MIT. Font Awesome Free retains Fonticons attribution and CC-BY 4.0 terms. Octicons retains GitHub's MIT notice; Lucide retains ISC and inherited notices. Of 45 observed SVG path tuples, 43 match installed icons exactly. Two optimized CSS tuples have source attribution: Lucide focus/download in the pinned SCSS. This does not assert equivalence of all SVG geometry.

FontLab's shared theme and the existing Adobe Fonts stylesheet remain external HTTPS services (theme.font is false). Their implementation/font bytes are not copied into this payload; reference notices below do not freeze future responses. Build dependencies and local/hosted publication have separate qualification.
